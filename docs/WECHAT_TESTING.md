# 微信内测试故障说明

更新日期：2026-07-05

## 当前现象

测试用户通过微信打开链接，页面可以正常显示，但点击“开始”后说话没有字幕。

## 初步判断

这类问题大概率不是页面加载失败，而是微信内置浏览器 / WebView 对网页语音识别支持不完整。

当前应用依赖浏览器内置 `SpeechRecognition` / `webkitSpeechRecognition`。这个能力不是所有浏览器都支持，而且在部分浏览器中会依赖远端识别服务和麦克风权限。微信内置浏览器即使能打开页面，也不等于能启动网页语音识别。

参考：MDN 将 `SpeechRecognition` 标记为 limited availability，并说明部分浏览器会使用服务端识别引擎。

- `https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition`

## 给测试用户的操作建议

1. 在微信内打开页面。
2. 如果页面提示“微信内打开可能无法识别”，点击微信右上角菜单。
3. 选择“在浏览器打开”。
4. Android 优先使用 Chrome 或 Edge。
5. iPhone 优先使用 Safari。
6. 打开后允许麦克风权限，再点击“开始”。

## 本轮已加的排查能力

- 自动识别微信内置浏览器，并显示明确提示。
- 如果当前浏览器不支持网页语音识别，会禁用开始按钮并提示原因。
- 如果点击开始后 8 秒没有任何识别结果，会提示换系统浏览器测试。
- 如果识别服务在短时间内反复启动/结束且没有结果，会停止空转并提示原因。
- 设置区新增“复制诊断信息”按钮，测试用户可以把设备、浏览器、权限和识别事件信息发回。

## 后续产品判断

如果微信内置浏览器始终无法稳定使用网页语音识别，MVP 需要明确把“微信内打开”降级为分发入口，而不是正式运行环境：

- 微信：用于分享链接和引导用户打开。
- 系统浏览器：用于实际语音识别。
- 后续后端流式识别方案：用于减少对浏览器内置 `SpeechRecognition` 的依赖。
